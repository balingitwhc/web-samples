# 🚀 Invoice Processor
A python script that extracts data from PDF to Excel

---

## ✨ Purpose
* Reads and extracts data from PDF Invoice and transfer's all relevant data into Excel
* Online converters had limits and most of the time would not convert properly due to how the PDF was designed/formatted
* We needed something that could work offline and with specific formatting
* Created with Python and a Java Library
